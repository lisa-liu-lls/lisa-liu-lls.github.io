# Lisa Liu — Personal Website

This is a static HTML website ready for GitHub Pages.

## Pages
- `index.html` — Home
- `research/index.html` — Research
- `experience/index.html` — Work Experience
- `teaching/index.html` — Teaching
- `coursework/index.html` — Coursework

Upload the **contents** of this folder to the root of your GitHub Pages repository. With a username.github.io repository, the URLs will be `/research/`, `/experience/`, `/teaching/`, and `/coursework/`.

## Edit
Open any `index.html` file in VS Code or another text editor and change the placeholder text in square brackets. The shared dark/light theme is embedded in each page and remembers the visitor's choice in local storage.

The home page references `photo.jpg` and `cv.pdf`, which were not included in the uploaded HTML file. Add those files alongside the root `index.html` to show your photo and make the CV link work. Update the GitHub icon link to your own GitHub profile when ready.
